# فيلورا — مساحة مالية ذكية

> **Read in English:** [README.md](./README.md)

فيلورا منصة مالية شخصية متكاملة (MERN) بتجمع **المصاريف والفواتير والاشتراكات
والأقساط وأهداف الادخار والميزانيات ومالية العائلة وتحليلات الذكاء الاصطناعي
والمدفوعات** في مساحة واحدة ثنائية اللغة (عربي / إنجليزي)، بدعم كامل للوضع
الفاتح والغامق، وتشتغل **أوفلاين** وتتسطب كـ **تطبيق PWA**.

## ✨ المميزات

### 📊 لوحة التحكم
- نظرة مالية شاملة، كروت إحصائيات، أحدث المصاريف، الفواتير القادمة
- **رسم بياني لاتجاه المصاريف** (آخر 6 شهور)
- مركز تنبيهات: قراءة، **حذف فردي وجماعي**، تعليم الكل كمقروء
- بانر المساعد الذكي، شارة الخطة الحالية
- تفعيل إشعارات المتصفح + **معالج الإعداد الأولي** للمستخدم الجديد

### 💸 المصاريف
- إضافة/تعديل/حذف مع 7 تصنيفات وبحث وفلاتر
- **تصنيف تلقائي بالذكاء الاصطناعي** — اكتب "كشري" يقترح "أكل"
- تصدير CSV متوافق مع الإكسل العربي

### 🧾 الفواتير
- إدارة كاملة مع حالات (مدفوعة/معلقة/متأخرة) وتواريخ استحقاق
- **رفع صورة الفاتورة** (معاينة، حتى 8MB، JPG/PNG/WebP/GIF/HEIC)
- **مسح الفواتير بالذكاء الاصطناعي** — صوّر الفاتورة والفورم يتملي لوحده
- تصدير CSV وتذكيرات دفع

### 🔁 الاشتراكات
- إدارة كاملة بدورات تجديد ومواعيد
- **النشر التلقائي**: التجديد بينزل كمصروف لوحده ويقدم المعاد (قابل للإيقاف لكل اشتراك)
- زرار **"تم الاستخدام"** + **تنبيهات تلقائية للاشتراكات المهجورة** (60+ يوم)
- تصدير CSV

### 📦 الأقساط · 🎯 الأهداف · 💰 الميزانيات
- أقساط بجداول ونسب إنجاز
- أهداف **بمساهمة سريعة** (+500 بضغطة، بسجل تاريخ، واكتمال تلقائي عند الهدف)
- **ميزانيات شهرية لكل تصنيف** بشرائح تقدم وتنبيهات عند 80% و100%

### 👨‍👩‍👧 مساحة العائلة
- إنشاء/انضمام بكود دعوة (حتى 10 أفراد)
- إجمالي شهري لكل فرد، إدارة الأعضاء، خروج/حل
- **ميزانية عائلية مشتركة** بتقدم حي

### 📅 التقويم المالي
- الفواتير والأقساط والتجديدات ومواعيد الأهداف على شبكة شهرية
- تفاصيل اليوم المختار وإجماليات الشهر، عربي/إنجليزي

### 🤖 ذكاء فيلورا الاصطناعي (Gemini)
- مساعد محادثة + تحليلات الصرف
- تصنيف تلقائي للمصاريف (مع بديل محلي لو الخدمة واقعة)
- قراءة صور الفواتير

### 💳 الخطط والمدفوعات (Paymob)
- خطط مجانية/بريميوم/عائلية بدفع شهري/سنوي
- الخطة الحقيقية ظاهرة في كل حتة (داشبورد، بروفايل، إعدادات)

### 🔔 التنبيهات (3 قنوات)
- داخل التطبيق (قراءة/حذف)، **إيميل** (حسب تفضيلاتك)، **إشعارات متصفح** (VAPID — توصلك والتطبيق مقفول)

### ⚙️ الإعدادات والبروفايل
- اللغة، العملة (جنيه/دولار/يورو — مطبقة في كل الأرقام)، بداية الشهر
- تفضيلات التنبيهات، الثيم الفاتح/الغامق، لون التمييز
- تغيير كلمة السر، الجلسات، **نسخة احتياطية JSON تصدير/استعادة**، حذف الحساب
- بروفايل بكارت عضوية ورفع صورة وأقسام متراصة

### 🌍 التجربة
- **عربي ⇄ إنجليزي كامل** باتجاه RTL وخط Cairo
- **ثيم فاتح + غامق** محفوظ بين الجلسات
- **أوفلاين أولاً**: طابور عمليات، نسخ محفوظة من البيانات، بانر وشارة مزامنة
- **PWA**: ملف تعريف + أيقونات مولدة + Service Worker (للإنتاج)
- سياسة خصوصية وشروط استخدام وصفحة 404 وحماية روابط الأدمن

### 🛡️ لوحة الإدارة (`/admin`)
- إحصائيات، إدارة المستخدمين وتفاصيلهم، المدفوعات، الخطط، تحليلات الإيرادات
- **بث إعلانات** لكل المستخدمين (داخلي + push) مع عدادات التسليم

### 🔒 الأمان
- Helmet وCORS من المتغيرات وتحديد معدل لمحاولات الدخول
- JWT (ساعة) بمعالجة 401 عامة، تشفير bcrypt
- تفعيل إيميل بأكواد (انتهاء + حد محاولات)، حماية أدوار
- رفع ملفات مقيد نوعاً وحجماً بأسماء معقمة ورسائل واضحة
- إقلاع صارم عند انقطاع قاعدة البيانات (رسالة واضحة بدل الكراش)

## 🚀 التشغيل

### المتطلبات
- Node.js 20+، رابط MongoDB، بريد Gmail + كلمة تطبيق، مفتاح Gemini

### 1. الباك إند
```bash
cd server
npm install
# اعمل ملف .env (المتغيرات تحت)
npm run dev        # على http://localhost:7000
```

### 2. الفرونت
```bash
cd client
npm install
# اعمل ملف .env (المتغيرات تحت)
npm run dev        # على http://localhost:5173 (أو أول بورت فاضي)
npm run build      # نسخة الإنتاج (+ تسجيل الـ Service Worker)
```

> لو Vite اختار بورت `5174`، الباك إند بيقبل الاتنين — استخدم الرابط اللي يطبعه.

## 🔑 متغيرات البيئة

### `server/.env`
| المتغير | الغرض |
|---------|-------|
| `MONGO_URI` | رابط الاتصال بقاعدة البيانات |
| `PORT` | بورت الـ API (الافتراضي `7000`) |
| `JWT_SECRET` | سر توقيع التوكن |
| `FRONTEND_URL` | الدومينات المسموحة (ممكن كذا واحد بفاصلة) |
| `USER_EMAIL` / `USER_APP` | بريد الإرسال + كلمة التطبيق |
| `GEMINI_API_KEY` | مفتاح ذكاء جوجل |
| `OPENAI_API_KEY` | بديل اختياري |
| `PAYMOB_API_KEY` / `PAYMOB_SECRET_KEY` / `PAYMOB_INTEGRATION_ID` / `PAYMOB_HMAC_SECRET` | مدفوعات Paymob |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` / `VAPID_SUBJECT` | مفاتيح إشعارات المتصفح |
| `NODE_ENV` | `development` / `production` |

### `client/.env`
| المتغير | الغرض |
|---------|-------|
| `VITE_API_URL` | رابط الباك إند (الافتراضي `http://localhost:7000`) |
| `VITE_PAYMOB_PUBLIC_KEY` | مفتاح Paymob العام للدفع |

## 🧪 التحقق
- بناء الإنتاج ناجح، وفحص ESLint نضيف
- تجارب API حقيقية: دخول ← تفعيل ← ميزانيات/عائلة/أهداف/push/نسخة/بث، ورفض المدخلات الغلط (400) والصلاحيات (403)
- +1000 مفتاح ترجمة شغالين باللغتين، واتجاه RTL وثيم ولغة وعملة محفوظين

## 📝 ملاحظات
- جدولة يومية 9 صباحاً (القاهرة): تذكيرات الفواتير والأقساط والأهداف، فحص الاشتراكات المهجورة، النشر التلقائي
- منع تكرار التنبيهات بـ `(user, relatedId, reminderType, reminderDate)` — والشهرية بتتجدد تلقائياً
- الـ Service Worker بيتسجل في نسخ الإنتاج بس عشان التطوير ميقدمش ملفات قديمة
- السيرفر بيسجل مشاكل الدخول في `server/logs/auth-errors.log` (بتتمسح فوق 1MB)
